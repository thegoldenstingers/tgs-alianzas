THE GOLDEN STINGERS (TGS) — GitHub Pages

ARCHIVO PRINCIPAL
- index.html: página completa, adaptable a computadoras y celulares.

ANTES DE PUBLICAR
1. Abre index.html y busca: CAMBIA-ESTE-CORREO@example.com
2. Reemplázalo por el correo que recibirá las solicitudes de alianza.
3. Guarda los cambios.

PUBLICAR EN GITHUB
1. Abre tu repositorio tgs-alianzas.
2. Pulsa Add file > Upload files.
3. Sube index.html (puedes subir también este README).
4. Pulsa Commit changes.
5. Ve a Settings > Pages.
6. En Build and deployment, elige Deploy from a branch.
7. Selecciona la rama main y la carpeta /(root); pulsa Save.
8. Espera unos minutos. El enlace suele tener este formato:
   https://TU-USUARIO.github.io/tgs-alianzas/

NOTA
El formulario prepara un correo electrónico; no almacena ni envía datos por sí solo.
